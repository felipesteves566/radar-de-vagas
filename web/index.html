Conectar ao GitHub (uma vez)

Para o app gravar a busca no seu repositório, ele precisa de uma chave. Ela fica salva só neste aparelho.

  1. Abra criar chave no GitHub.
  2. Nome: Radar. Expiração: 1 ano.
  3. Repository access: Only select repositories → radar-de-vagas.
  4. Permissions → Repository: Contents: Read and write e Actions: Read and write.
